# CampusGPT：课程资料检索助手

面向课程复习场景的本地 PDF 检索应用。用户上传资料后，系统按页提取文本、进行重叠切分、建立字符 TF-IDF 索引，并根据问题返回相关片段与来源页码。

## 功能流程

```text
上传 PDF → 按页解析 → 文本切分 → 建立本地索引
                                  ↓
来源页码 ← 返回相关片段 ← 相似度排序 ← 输入问题
```

当前版本是 **AI 应用的检索基础模块**：没有调用大模型生成答案，也没有使用 Chroma。仓库明确区分“检索结果”与“生成式回答”，避免夸大实现范围。

## 测试与改进

- 使用 `unittest` 编写 **14 个自动化测试方法**。
- 覆盖正常上传、损坏 PDF、空白 PDF、扫描版限制、空索引、无匹配、排序、索引复用、切分边界和来源页码。
- 将词级 TF-IDF 调整为字符片段匹配，改善连续中文问题的命中表现。
- 增加空文本检测和相似度阈值，避免空白资料进入检索流程、无关问题强行返回内容。
- 保留页码元数据，修复切分后来源页码错误。
- 上传内容仅在内存处理，限制单文件 20 MB；扫描版 PDF 需要先 OCR。

这些测试用于验证功能与回归，不代表真实用户问答准确率。检索质量仍需使用人工标注的问题集单独评估。

## 运行

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## 自动化测试

```bash
python -B -m unittest discover -s tests -v
```

## 目录

```text
app.py          Streamlit 页面与交互流程
rag/            PDF 解析、文本切分和本地检索
tests/          核心逻辑与 UI 边界自动化测试
requirements.txt
```

## 后续方向

建立人工标注的问题—页码数据集，增加 Precision@K、Recall@K 等检索评估；在检索质量稳定后，再接入生成模型并验证引用是否真正支持答案。
